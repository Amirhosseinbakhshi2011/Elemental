# Elemental ⚛️🌌

جدول تناوبی سه‌بعدی سینمایی.

عناصر مثل سیارات کوچک توی فضا شناورن، رنگ‌بندی بر اساس دسته شیمیایی، و با کلیک کردن روی هر عنصر می‌تونی مدل پوسته‌های الکترونی‌ش رو ببینی.

**ساخته شده توسط امیرحسین بخشی**

## ویژگی‌ها

- جدول تناوبی سه‌بعدی با چیدمان واقعی
- رنگ‌بندی بر اساس دسته (قلیایی، واسطه، گاز نجیب و ...)
- انیمیشن شناور نرم
- مدل پوسته‌های الکترونی (Bohr-style) هنگام انتخاب عنصر
- اطلاعات کامل به فارسی + انگلیسی
- کنترل کامل دوربین (چرخش، زوم، پن)

## اجرا

```bash
npm install
npm run dev
```

برو روی [http://localhost:3000](http://localhost:3000)

## تکنولوژی

- Next.js 14
- React Three Fiber
- Three.js + Drei
